## 1. 006·007 적용

1. `보안점검-읽기전용.sql` 실행(사전): S-6 전부 false, S-1·S-3 가 11-03 결과와 같은지.
2. `보안패치-006-007-적용.sql` 전체를 한 번에 실행. 사전 점검 → 원본 보존(security_patch_backup) → 006 → 007 → 확인 1행 → commit.
   - 어느 문장이든 실패하면 배치 전체가 되돌아간다(반쯤 적용 없음).
   - 확인 행: trigger_role_guard=true, is_admin_checks_active=true, is_manager_or_admin_checks_active=true, backup_rows=2.
3. `보안점검-읽기전용.sql` 재실행(사후): S-6 trigger_role_guard·fn_role_guard·is_admin_checks_active·is_manager_or_admin_checks_active·backup_table = true.
4. 업무 확인(사용자): 대표 로그인 → 직원관리 저장·역할 변경, 인사담당 로그인 → 직원 정보 수정(이름·부서·시급), 야근 승인 화면, 급여 화면 진입.

**장애 대응**: 907(보존 원본으로 복원) → 906(트리거 제거) 각각 한 번에 실행 → S-6 확인. 데이터 변경 없음, 앱 변경 없음.
- 감지: 인사담당·대표가 직원관리 저장 시 ROLE_ADMIN_ONLY 외 오류, 활성 관리자가 Unauthorized/0행.
- 바뀌는 객체 4개(함수 2 신규·교체 2)뿐이라 복구는 즉시 가능하다.
