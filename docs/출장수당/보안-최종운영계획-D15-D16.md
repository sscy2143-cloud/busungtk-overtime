### 1. 퇴사자 3명 Auth Ban
- 필요: 비활성인데 로그인 가능한 상태 해소(새 로그인·토큰 갱신 차단)
- 변경: Supabase Auth 사용자 3명의 ban_duration 만 설정. employees·기록·UUID 변경 없음
- 영향: 해당 3명 로그인 불가. 기존 액세스 토큰은 만료(최대 약 1시간)까지 유효하나 DB 쪽은 is_active 검사(007·010)로 이미 차단
- 복구: 복직 처리(Unban) 또는 ban_duration='none'
- 절차: (a) `보안점검-D15-비활성계정.sql` 실행 → 3명이 기존 확인 대상과 일치, banned=false 확인 → (b) 2번 배포 뒤 관리자 화면 "퇴직 처리"(이미 비활성이면 Ban 만 보충, steps: employee=already, auth=ok) 로 한 명씩 → (c) 같은 SQL 재실행으로 banned=true 확인
- 이 방식이면 SQL 직접 수정 없이 앱 API 로 처리되어 감사가 쉽다
