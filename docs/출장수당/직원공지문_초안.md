# 출장수당 전산 신청 안내 (초안 — 발송 전 사용자 검토·승인 필요)

> 이 문서는 초안입니다. 발송하지 않았습니다. 시행일·담당자·문의처는 사용자가 확정합니다.
> 금액·단가는 이 안내에 넣지 않습니다 (범위 밖).

## 짧은 판 (카카오톡·게시판용)

**[공지] 출장수당 신청, 근태 앱에서 하세요 — {시행일} 부터**

{시행일}부터 출장(근거리 현장 포함) 근무는 근태관리 앱 **"근무 신청 → 출장"** 에서 신청합니다.

- 입력은 **지역, 날짜, 현장 작업 시작·종료, 점심 사용 여부** 네 가지면 됩니다.
- 근무 유형과 이동시간은 회사 기준(지역별 표준 편도시간)으로 **자동 계산**되고, 신청 전에 인정시간을 미리 볼 수 있습니다.
- 숙박·야간·사무실 근무 후 출발 같은 경우만 추가 질문이 뜹니다.
- 동행 출장은 한 사람이 초안을 보내면 **각자 확인하고 각자 제출**합니다.
- 근무를 **마친 뒤** 신청하고, 관리자가 검토한 뒤 승인됩니다.

처음 한 달은 기존 방식(수기)과 **병행**합니다. 앱 신청이 어렵거나 계산이 이상하면 {담당자}에게 알려 주세요.

## 긴 판 (상세 안내)

### 1. 무엇이 바뀌나요
- 출장 인정시간을 사람이 계산하던 것을 앱이 **회사 기준(2026.10.26 최종본)** 대로 계산합니다.
- 계산 근거(표준 이동 구간, 적용 규칙)가 신청 화면과 관리자 화면에 똑같이 보입니다.
- 승인된 결과는 그대로 보존되어 나중에 바뀌지 않습니다.

### 2. 신청 방법
1. 근태 앱 → **근무 신청** → **출장** 선택
2. 지역(방문 순서대로), 당일/숙박, 날짜
3. 날짜마다 **현장 작업 시작·종료**, **점심 사용 여부**(기본: 사용)
4. 아래 "인정시간 미리보기" 확인 → **저장** → **제출**

### 3. 추가로 묻는 경우 (해당할 때만 펼쳐집니다)
| 상황 | 추가 입력 |
|---|---|
| 사무실에서 근무하다 출발 | 사무실 근무 시각 |
| 현장 작업 없이 이동만 (작업 취소 등) | 사유, 출발 시각 |
| 8시간 넘게 작업했는데 점심 외 휴게 없음 | 휴게 시각 |
| 도착 후 작업 시작까지 1시간 이상 대기 | 회사 지시 대기였는지 |
| 제주 | 실제 이동 시각과 항공권 등 증빙 |
| 경유·지연 | 추가 시간과 증빙 |

**실제 출발·도착 시각**은 기록용 칸이 따로 있습니다. 기억나지 않으면 **비워 두세요** — 표준시간을 대신 넣지 마세요. 계산에는 쓰지 않습니다.

### 4. 동행 출장
- 신청자가 동행자를 고르면 동행자에게 **초안**이 갑니다 (지역·일정·현장 시각만 복사).
- 동행자는 자기 점심·휴게 등을 확인한 뒤 **직접 제출**해야 신청이 됩니다. 신청자가 대신 제출할 수 없습니다.

### 5. "관리자 확인 필요" 표시
회사 규정이 아직 정해지지 않은 상황(예: 숙박 출장 중간일, 다음 날 09시를 넘긴 작업)은 **제안값**으로 계산되고 "관리자 확인 필요"로 표시됩니다. 관리자가 확인한 뒤 처리되며, 확인 전에는 급여에 반영되지 않습니다.

### 6. 시행 방식
- 시행일: **{시행일}** (사용자 확정)
- 첫 달은 수기 계산과 **병행 비교**합니다. 차이가 있으면 {담당자}에게 알려 주세요.
- 급여 반영 시점은 병행 기간과 노무 검토가 끝난 뒤 별도로 안내합니다.
